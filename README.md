# Pi Extensions

Personal pi coding agent extension collection.

## Extensions

- **browser** — Playwright-based web browsing (navigate, snapshot, interact, screenshot, evaluate JS)
- **role-override** — Replace default pi role with `~/.pi/agent/ROLE.md` or project-local `ROLE.md`

## Install

```bash
pi install git:github.com/Guilimao_Official/pi-extensions@v1.0.0
```

## Prerequisites (browser extension)

```bash
npm i -g @playwright/cli
playwright-cli install
```
